# 示例：设备调研的问题路径（中试型冻干机选型）

> **合成示例：品牌、型号、价格、文号、检测数据、报告名称、公众号名称均为合成示例，仅演示路径与引用格式。**
> 「设备 A / B / C」= 三家厂商的同档中试机型；「某厂商《XX 型号技术手册（示例）》」是不存在的文件。
> 所有数字都是示例值或结构性事实（如"报价 ≠ 中标价"），**不得当作真实市场数据引用**；真实运行须替换为一手可核验来源。
> 演示范围：输入与定档 → 维度激活 → 问题树 → 4 张详卡 → 可比性矩阵 → 死胡同降级 → 引用到句 → 覆盖度声明 → 复用清单。

---

## 1. 输入与定档

| 项 | 值 |
|---|---|
| target | 设备 A / B / C：三台同档中试型真空冷冻干燥机（有效搁板 2 m² 级，示例） |
| 用户原话 | "这三台哪台划算？性能差多少？市场上都什么价？同行买的谁？" |
| goal | 产出可上会的**可比证据包**：性能口径、3 年 TCO、横评可行性、市场规模量级 |
| 决策时点 / 买错代价 | 20XX-Q4 前定标；买错 ≈ 3 年折旧 + 数批料报废（示例口径） |
| 预算 | 35 节点 / 7 层 / 600 秒（示例；本例实际用 23 节点 / 5 层） |
| 检索截止 | 2026-10-26 |
| 复杂度定档 | **L3 交互 / 异质** |

**为什么是 L3 而不是 L2**（两条判据，任一成立即 L3）：

1. **排序随分层反号**：单班利用率下设备 C 的 3 年 TCO 最低；三班利用率下 A 的批次节拍假设占优——同一因素在不同分层下方向翻转（示例模型结论，非实测）。命中模式 **#3 效应修饰**。
2. **工况是阈值/非线性**：捕水能力从"空载"到"满载"存在非线性跌落（示例 40 → 26.4 kg/24h），跨工况相减会造出假差值。命中模式 **#8 阈值非线性**。

**定级留痕**：`complexity_level = L3`；命中模式 #3、#8（另在 §8 R3 记 #13 代理误差）；因预算未查的轴：主体（D9 关闭）、反馈动态（见 §8 R2）。L3 的两件必做（交互、分层）在本例中以**工况分层**与**利用率分层**并入 §5 矩阵，不另建九轴因素空间（理由见 §8 R2）。

## 2. 维度激活表（14 维逐条）

设备/装备类的必选集是 D1 D2 D3 D4 D5 D6 D11；其余维度逐条给出关闭理由与**承载位置**——关闭 ≠ 留白，找不到落点的关闭就是漏查。

| 维度 | 状态 | 为什么 / 由谁承载 |
|---|---|---|
| D1 目标与决策 | **激活** | 先把"划算"落成可判定的"3 年现金口径回本"（示例假设）；否则 TCO 无法定边界 |
| D2 定义边界口径 | **激活** | 「2 m²」「捕水 XX kg/24h」在 A/B/C 手册里不是同一件事，见 Q1 |
| D3 性能技术 | **激活** | 峰值 vs 持续、空载 vs 满载是本场景最大失真源，见 Q2 / 详卡① |
| D4 经济性 | **激活** | 报价 ≠ 中标价 ≠ TCO，见 Q3 / 详卡② |
| D5 市场与需求 | **激活** | TAM/SAM/SOM 口径错一位，结论错一个量级，见 Q5 / 详卡④ |
| D6 竞争与同行 | **激活** | 横评是买方最想要、也最常被伪造的交付物，见 Q4 / 详卡③ |
| D7 供应链产能 | 关闭 | 只买 1 台，产能/良率/上游议价不构成独立问题面；交期与备件停产并入 Q3.1、Q6.2 |
| D8 政策法规标准 | 关闭 | 示例设定该机型无强制准入（非压力容器、非 GMP 线）；验收标准只作 Q1.2 一条。**若实际涉 GMP 或压力容器，必须重启 D8** |
| D9 主体与采购链 | 关闭 | 谁拍板/谁使用/预算归属属委托方内部信息，公开检索无法闭合；缺此维不得给"买谁"的建议——连带 D13 关闭 |
| D10 时间路线图 | 关闭 | 单台采购把路线图退化为"交期 + 下一代是否 6 个月内发布"，分别并入 Q3.1、Q6.2 |
| D11 风险与反例 | **激活** | 买错的三种形态：验收不达标、备件停产、厂商退出中试市场，见 Q6 |
| D12 证据质量 | 关闭（字段承载） | 不设独立节点：证据等级与追溯链由每卡「证据」字段 + 矩阵「等级/是否可比」列强制承载；单独立维会与 D3/D6 产出同义节点（去重键冲突） |
| D13 决策含义 | 关闭 | 缺 D9（采购链）时写"该买谁"＝把证据包装成建议；只保留 D13 唯一可交付的部分——**反转条件**（§5 末），不写推荐 |
| D14 未解负空间 | 关闭（§8 承载） | 未解项以负空间清单 + 验证计划留档；升格为节点会再长出 5–8 个节点，超出 25 节点目标 |

## 4. 节点展开（详卡）

### 详卡①｜Q2.1 捕水能力：峰值还是持续，测试条件是什么
- **承接**：Q2 要"决定够用的指标"。A 手册写「≥40 kg/24h」、B 写「35」、C 写「32」（均为示例数值），按数字排 A>B>C。但 Q1.1 已发现 A 的"2 m²"是腔体面积、B/C 是有效搁板面积，且 A 的数注了"空载"、B/C 注"满载"——三个数不在同一条件上，排序无效，必须先拆口径。
- **需要什么**：① 三本手册的"测试条件"栏（不是参数栏）；② 招标文件技术参数表与投标响应表；③ 第三方检测报告或 SAT 验收记录；④ 用户近 12 个月批次记录（装载量/周期/失败批）。
- **怎么找**：`"冻干机" "捕水能力" "测试条件"`；手册先看目录再定位参数表（A 在第 3 章表 2）；公共资源交易平台按"冻干机 + 搁板面积"检索中标公告附件；向三家索要 SAT 报告模板；行业会议论文与用户群实测帖。
- **困难**：峰值是"冷阱极限温度 + 空载 + 24h 累计"的上限值，持续值是"满载 + 搁板控温 + 连续运行"的稳定值，同一台机器可差 30% 以上（示例 40 → 26.4）；手册通常不在参数旁写条件，条件藏在表注或"说明"段；条件一变排序可能反转（示例：按峰值 A>B>C，按满载持续 C>A>B）。
- **分支**（≥2）：
  - Q2.1.1 追条件：书面确认温度/装载/终点压力/是否连续 → 得到即转"可比"。必要性：条件是**可谈判信息**，通常比数据本身容易拿到。
  - Q2.1.2 找同条件第三方数据：转入 Q4.2；失败即死胡同（§6）。
  - Q2.1.3 自家物料 3 批小试（需实验 / `needs_human`）：唯一能闭合"我这批料"口径的路径，成本最高，留给最终二选一阶段。
- **闭合判据**：≥2 台设备在**同一组书面条件**下有数值（冷阱 ≤ −75 °C、搁板 ≤ −40 °C、装载 8 kg/m²、连续 24h、终点 ≤ 10 Pa；阈值本身是示例设定，实际按物料与工艺定），且条件写进矩阵备注；达不到记"不可比"，不进排序。
- **证据**：C1（A 手册 p.12 表 2 第 4 行，标"空载"，C 级）/ C3（第三方检测摘要，满载 26.4，B 级）/ C4（公众号把 40 当"实际产能"，回溯后判 D，仅作线索）。
- **unknown 处理**：只有峰值且无条件下 → 降级为"上限参考"，矩阵标 ❌；动作 = §6 验证计划第 1 项（写进验收条款）+ 第 2 项（索取运行日志）。**不得**用"上限参考"排序后写成结论。

### 详卡②｜Q3.1 报价、中标价、成交价，以及 TCO 的六项
- **承接**：Q3 要 3 年 TCO。第一道障碍不是"贵不贵"，而是"价格"在设备交易里至少是三个不同的数。
- **需要什么**：含税/不含税报价单（含运费、安装、培训）、中标公告（金额 + 包内容）、合同条款（付款、质保、备件、性能罚则）、耗材清单与单价、能耗（铭牌功率 × 负荷率）、停机损失（批毛利 × 停机天数）。
- **怎么找**：招标平台检索同类项目中标公告（2–3 个样本）；向三家索取**同口径报价**（指定含税 + 含安装 + 3 年维保 + 单台 + 含培训）；厂商官网/年报耗材价；车间电价与批毛利由委托方提供（示例 0.8 元/kWh）。
- **困难**：报价是挂牌价，成交价常低 10%–20%（示例区间；账期/打包/以旧换新）；中标价常含安装但**不含公用工程**（示例：中标 108 万，公用工程另计 12 万）；含税口径不一致会让 TCO 差 10% 以上（示例）；隐性项是耗材与停机（示例：A 真空泵油+密封件 3 万/年，B 1.8 万/年）。
- **分支**（≥2）：
  - Q3.1.1 折算同口径：含税/含安装/含 3 年维保/单台。必要性：不做这一步，后面所有比较都建立在不同的价格定义上。
  - Q3.1.2 用 ≥2 个中标价校验折扣率（示例：报价 120 万 → 中标 108 万，折 10%）。
  - Q3.1.3 拿不到中标价 → 用报价算 TCO 并标"上界"，折扣率做 0 / 10 / 20% 三档敏感性。
- **闭合判据**：TCO 六项（采购/安装/能耗/耗材/维保/停机）每项有来源或明确标"缺失"；三家在同一折扣假设下比较；输出"利用率 × 电价 × 折扣"三参数敏感性区间。
- **证据**：C2（中标公告第三条 + 附件 1，A 级事实）/ C1（铭牌功率，C 级）/ 假设表（电价、批毛利、利用率，均标示例）。
- **unknown 处理**：缺运维记录 → TCO 标"**下界**"（只含采购 + 安装 + 能耗），并在结论处显式声明"结论只覆盖下界"；禁止用"最低价 = 最划算"替代 TCO 结论。

### 详卡③｜Q4.2 同条件横评存在吗（先验证前提，再谈比较）
- **承接**：Q4.3 要交一张矩阵，矩阵的前提是"存在同条件数据"。Q4.2 就是去证伪这个前提，它的结论决定矩阵是"横评"还是"参数并列 + 未验证"。
- **需要什么**：独立第三方（CMA/CNAS）检测报告、行业期刊/会议评测、用户社群实测帖、退机与索赔记录、招标技术参数响应表（同一条款下多家的自填值）。
- **怎么找**：检测机构报告的公示摘要；CNKI/会议论文 `冻干 能耗 测试`；用户群关键词 `验收 不达标 冻干机`；招标平台按同一技术条款横向比对多家响应表。
- **困难**：几乎没有机构做"三台同条件横评"（样机成本高，样机由厂商提供则利益冲突）；能搜到的"横评"多由厂商委托（C 级）；测试物料不同（纯水 vs 含蛋白料液）会让捕水量不可比；招标响应表能给"同条款"数据，但那是**厂商自填值**，不是实测。
- **分支**（≥2）：
  - Q4.2.1 找到独立第三方同条件数据 → 核对条件，矩阵标 ✅。
  - Q4.2.2 只找到厂商委托的横评 → 利益冲突，C 级，作线索不作排序依据。
  - Q4.2.3 找不到 → **死胡同**，矩阵降级为"参数可比但未验证"（§6）。
- **闭合判据**：要么 ≥2 台设备有同条件第三方数据（✅），要么明确写出"未检索到同条件横评"并附验证计划与降级使用规则；**不允许**把不同条件的数据拼成一张"横评表"。
- **证据**：C3（单台第三方摘要，B 级）/ C4（媒体转述，D 级）/ C2（响应表，可作同条款比较但为自填）。
- **unknown 处理**：无横评 → 不写"B 更好"，只写"B 在 X 指标标称领先，未同条件验证"；把不确定性放进**合同罚则**，而不是放进结论措辞。

### 详卡④｜Q5.1 TAM/SAM/SOM：先把"同类"和"金额口径"钉住
- **承接**：Q5 问"市场多大、同类产品是什么"。但 Q1 已证明"2 m² 中试机"在不同统计里归属不同（实验室仪器 / 制药装备 / 通用干燥设备）——不定口径，"市场 XX 亿"这句话没有指称对象。
- **需要什么**：协会统计、海关 HS 编码进出口量、上市公司年报分部收入、招标平台年成交台数与金额、第三方机构报告（含委托方与样本说明）。
- **怎么找**：海关编码按"冷冻干燥设备"检索；年报检索"冻干设备 / 制药装备"分部；招标平台按年统计"冻干机"成交；协会报告看发布方、赞助方与脚注里的样本说明。
- **困难**：TAM 常是"总产值 × 中试占比"，系数无来源；台数×金额混算时用终端价得出厂规模，虚高；需求可能由科研经费/补贴驱动，退坡即断崖；多份第三方报告互相引用同一份源数据，看似"多源一致"实为**单源重复**。
- **分支**（≥2）：
  - Q5.1.1 自上而下：C5 协会口径 × 中试占比（系数必须给来源，否则标 D）。
  - Q5.1.2 自下而上：招标年成交台数 × 中标均价（可复核，但样本偏公共机构）。
  - Q5.1.3 两法差异 > 30% → **并列两口径，禁止取平均**，用海关量做第三校验。
- **闭合判据**：TAM/SAM/SOM 三档且每档标口径（台数/金额、含税/不含税、出厂/终端、整机/交钥匙）；≥2 个独立口径且差异可解释；单一来源时标 C 并注明委托方。
- **证据**：C5（协会报告：台数 + 出厂口径，C 级）/ C2（中标金额可做自下而上样本）/ 海关数据（未取到，标 `unchecked`）。
- **unknown 处理**：只有一份付费报告 → 只给"量级 + 驱动因素"，不给单点数字；差异原因写清（含生产型/含出口/样本偏公共机构为假设），并列入 §8 负空间。

## 5. 可比性矩阵（含不可比台账）

**这是设备调研的核心，也是多数报告伪造的地方。** 图例：✅ 同条件可比 / ⚠️ 口径部分对齐（附条件）/ ❌ 不可比（只列示，不进排序）。

| 指标（口径） | 设备 A | 设备 B | 设备 C | 证据等级 | 可比 |
|---|---|---|---|---|---|
| 捕水能力·峰值（空载 24h） | ≥40 kg | — | — | C（C1） | ❌ 仅 A 有 |
| 捕水能力·持续（满载 8 kg/m²） | 26.4 kg | 未提供 | 未提供 | B（C3）/— | ❌ 仅单台 |
| 冷阱最低温度（空载） | −80 °C | −75 °C | −70 °C | C | ⚠️ 均空载，持续降温未给 |

> **上表所有数值均为示例合成**，仅演示"等级 + 可比性"两列怎么填，不是任何真实机型的参数。

**不可比台账（按指标族合并为 5 项，每项必须写处理动作，否则矩阵只是装饰）**：

| 不可比项 | 为什么不可比 | 处理动作 |
|---|---|---|
| 捕水能力 | A 是空载峰值，B/C 无同条件持续值 | 不进排序；验证计划 1（验收条款）+ 2（运行日志） |
| 搁板均一性 | 测点数 3/9/5，位置未说明 | 要求统一"9 点、空载与满载各测一次" |
| 报价 | 维保/安装/税口径不同 | 折算同口径 + 索取书面同口径报价（Q3.1.1） |
| 3 年 TCO | 运维与停机数据缺失 | 只做下界 + 敏感性；不写"最便宜" |
| 噪音/振动 | 测距与背景噪音未给 | **放弃**，不进矩阵（写进 §8 负空间） |

**交叉判断（总纲 §8，8 对固定检查）**：本场景直接命中的两对是 **D3 性能 × D4 成本（性价比：单位性能的成本）** 与 **D4 成本 × D11 风险（坏情景下单位经济性是否仍成立）**，分别落在矩阵与"TCO 下界"上；**D5 × D8（政策依赖度）** 用一句交代"该机型需求不受补贴驱动（示例设定）"，否则会把政策红利当真实需求；其余 5 对（D6×D7 供给壁垒、D5×D9 可达性、D6×D9 渠道锁定、D10×D1 时点对齐、D11×D10 暴露窗口）因 D7/D8/D9/D10 关闭而标 `checked-none`，理由即各维关闭理由，不重复论证。

**分层检查（L3 必做）**：以"利用率"为分层维度做示例敏感性——利用率 30%（单班，示例）时 C 的下界 TCO 最低；75%（三班，示例）时 A 因批次节拍假设反超。**这是模型结论、不是实测结论**：节拍与故障间隔取自厂商自述（C 级），只用于说明"排序会随分层反转"，不用于推荐机型。

**结论强度与反转条件**：✅ 仅 2/12 → 当前只能声称"标称参数并列 + 成本下界可比"，不能声称"性能排序"。**反转条件**：若获得任一台的同条件满载数据，或任一家接受性能罚则条款，则该台的 ❌ 升为 ⚠️ / ✅，届时重跑分层敏感性并重新定结论。

## 6. 死胡同：Q4.2「不存在同条件横评」→ 降级为"参数可比但未验证"

**撞墙过程（示例）**：3 轮检索（检测机构目录 / 学术库 / 用户社群）+ 2 轮厂商询价 → 未检索到覆盖这三台机型的独立同条件横评。A 书面答复"满载测试条件属商业机密"；B 称"可在 SAT 现场按贵方条件测"；C 称"未做过满载连续测试"。

**为什么不能拼表**：把不同条件的数据并列，等于把"标称参数"写成"实测性能"。这是设备报告最常见的伪造形态（对应退化形态里的"口径混算"）。

**降级声明（可直接抄）**：
> 三台设备在满载 8 kg/m²、连续 24h、冷阱 ≤ −75 °C、终点 ≤ 10 Pa 条件下的捕水能力**未获验证**；现有数据仅支持"标称参数可比"，不支持"性能排序"。任何排序结论都必须标注该前提。

**验证计划（把不确定性换成动作）**：

| # | 动作 | 成本/周期（示例） | 闭合效果 |
|---|---|---|---|
| 1 | 统一测试条件写进合同验收条款（SAT），不达标按性能罚则扣款 | 0 / 随交付 | 直接消解风险，最优 |
| 2 | 索取近 12 个月同类客户脱敏运行日志 | 0 / 依赖商务 | 得到"真实持续值"的替代证据 |
| 3 | 付费第三方检测（CNAS，2 台样机） | 4 万元 / 2–3 周 | 该指标由 ❌ 升 ✅ |
| 4 | 自家物料 3 批小试 | 样品 + 工时 / 4–6 周 | 闭合"我这批料"的口径（`needs_human`） |
| 5 | 若 1–4 全失败：不排序，改为风险定价（C 级参数 + 罚则 + 分批采购） | 0 | 结论强度明示为"参数并列" |

**教训一行**：死胡同的产出不是"没结论"，而是**把结论的边界写成可执行的验证动作**。

**C4**｜`source_type: media`（公众号）｜「示例产业观察」（公众号，示例）｜《一台冻干机省 30 万？先看这三个参数（示例）》｜`2026-08-14`｜`locator: {kind: paragraph, value: "第 6 段"}`｜`chain_length: 2`｜**等级 D**

**C5**｜`source_type: industry_report`｜某行业协会《20XX 年中国冻干设备市场概况（示例）》｜`published_at: approx:20XX-05`｜`locator: {kind: section, value: "第 3 节第 2 段"}`｜`chain_length: 1`｜**等级 C**
> 原文：「20XX 年国内中试型冻干机销量约 420 台，市场规模约 6.8 亿元（出厂口径，不含安装与公用工程）。」

**字段与 `schemas/citation.json` 对齐**：`locator.kind` 取 `page` / `clause` / `paragraph` / `section` / `timestamp`；`chain_length ≥ 2` 必须尝试回溯一手并记 `primary_source_found`；`grade` 按**最弱一环**定，不按被引论文的等级定；`evidence_track` 默认 `sentence`（数据源走 `reproducible_query`、内部/访谈走 `accountable_provenance`），`snapshot` 存原文快照 + sha256 以防链接失效。本条示例里 C4 正是"回溯成功、等级仍降"的反面教材。**可追溯率 5/5 = 100%**，其中 1 条回溯成功仍判 D、1 条回溯失败判 D——**可追溯 ≠ 可用**，这是 D12 的两条独立判据。

## 9. 设备调研复用清单（换一台设备照抄）

**五个必问**（每个都能独立毁掉一份报告）：
1. 这个数字的**测试条件**写在哪？（空载/满载、连续/单次、测点几个）
2. 这个价格**含什么、不含什么**？（税、安装、公用工程、维保、培训）
3. 有没有**同条件**的第三方数据？没有就必须在矩阵标 ❌，而不是留空。
4. 市场规模是**台数还是金额**、**出厂还是终端**、整机还是交钥匙？
5. **谁买过、谁退过、谁停产了**？（退出者清单是 D11 的最低证据）

**三个必交产出**：可比矩阵（含 ❌ 台账）/ TCO 六项表（缺项标"下界"）/ 验证计划（含合同罚则）。

**三条禁令**：不用不同条件的数据拼横评；不取平均抹平口径差；不把媒体数字放进矩阵（可作线索）。

**一句判据**：矩阵里 ✅ 不足一半时，结论强度只能叫"参数并列"，不能叫"选型建议"。
