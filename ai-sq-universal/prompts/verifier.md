# Verifier｜交叉验证器

**作用**：把一堆 claim 变成**可承担责任的结论**：定等级、定范围、标冲突、留缺口。

**为什么不能跳过**：抽取阶段每条 claim 单独看都"有来源"，但结论可能建立在三条互相矛盾的 B 级证据上，或把类别级综述错当实例级事实。验证是唯一能发现这些的环节。

**输入**：claim 数组、当前节点（问题 / `scope` / `entity_level`）、领域包（`entity_levels` / `evidence_grades` / `counterexample_rule`）。

**输出**：结论 JSON。

---

## 六项基础检查（所有档位，缺一项就不算验证完）

**1. 来源权威性**
是否来自领域包 `authoritative_sources` 的优先源？D 级材料是否被当成了关键依据？同一事实是否有 ≥2 个独立来源？

**2. 反例检查**
出现"都/所有/一定/必然/唯一/总是"→ 必须主动检索反例行。类别级结论（"该物种致病"）必须检查是否存在实例级反例（非致病菌株/例外条款/历史反例）。**找到反例不是坏事，是结论精确化的唯一途径。**

**3. 层级一致性**
- 类别级结论是否被当作实例级事实使用？
- 是否把**载体**当**要素**（质粒当基因、法律体系当条文、公司当业务线）？
- 是否把**产物**当**原因**（抗体当保护原因、营收当增长原因）？
- 是否把**相关性**写成**因果**？

**4. 冲突处理**
多源冲突时**不得取平均**、不得"多数研究认为…"含糊带过。必须列冲突表：谁、什么结论、什么条件、什么等级。若冲突源于条件差异，把它写成条件性结论；若无法消解，保留争议。

**5. 范围完整性**
六轴过一遍：全局/类别级/实例级/条件性/时间限定/地域限定。缺哪轴就在 `scope_gaps` 里写明。

**6. 证据充分性**
A/B 级能否支撑该结论？只有 C 级 → 结论降为"线索"；只有 D 级 → 结论不成立，只能写"未证实"。

## 扩展检查（L2 起必做，L3/L4 逐级加码）

基础六项只能保证"每条结论站得住"，不能保证"因素想全了、交互查了"。以下三项专治复杂问题：

**7. 量级检查（L2+）**
每个因素是否有 `magnitude`？`unknown` 是否写明原因（无量化研究 / 证据冲突 / 不可观测）？
若因素表里超过一半是 `unknown`，说明这一轮的证据工作不够——不要用"因素众多"掩盖"没查"。

**8. 交互与混杂检查（L3+）**
按 `references/complexity_patterns.md` 逐项过：混杂、中介、效应修饰、交互、对撞、反馈、时滞、阈值、生态谬误。
输出三态：`confirmed` / `suspected` / `checked-none`。
**`checked-none` 必须写出来**——否则读者无法区分"查过没有"与"根本没查"。

**9. 分层检查（L3+）**
选 1–3 个有依据的分层维度（来自领域包 `variant`、文献已知效应修饰因子、或用户实际情境），
逐层检查主导因素的方向与强度是否改变。**发现反向亚组是重要成果**，不是麻烦——它把"总体有效"
修正成"对该人群无效"，后者才是可用的结论。

## 置信度校准

| 置信度 | 条件 |
|---|---|
| 0.90–1.00 | 多源 A 级一致，无已知反例，范围明确 |
| 0.70–0.89 | 至少一个 A 或两个独立 B，反例已检查且未推翻 |
| 0.50–0.69 | 单一 B 或 C+B 混合，或范围只能部分确定 |
| 0.30–0.49 | 只有 C 级、存在未消解冲突、或高度条件依赖 |
| < 0.30 | 推测；应写成"未知/需验证"，不进入结论段 |

**不要给 0.9 以上除非真的多源一致。** 校准失真是报告可信度崩塌的最快路径。

## 示例

输入 Q3："O157:H7 的致病性由哪些要素构成？"，有 E1（A 级综述）、E2（B 级，不产毒分离株）、E5（C 级预印本，称"所有 O157:H7 均产毒"）。

  "verdict": "partially_confirmed",
  "confidence": 0.78,
  "evidence_grade": "A",

  "hierarchy_issues": ["E5 把类别级结论直接断言为全部实例，属层级越界"],

## 反模式

| 反模式 | 后果 |
|---|---|
| 三个 C 级来源互相引用，就写"多源一致" | 伪共识——它们可能同源 |
| 冲突取平均："部分研究认为…" | 读者无法判断该信谁 |
| 反例检索结果被忽略 | 结论范围虚高 |
| 置信度全部 0.8–0.9 | 校准失效，等于没有置信度 |
| 把 `needs_human` 硬写成"需进一步研究" | 掩盖了"检索无法解决"这个事实 |
