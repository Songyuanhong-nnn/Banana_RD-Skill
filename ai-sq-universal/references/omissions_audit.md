# 遗漏审计记录 / Omissions Audit

**这份文件记录"重复去查有没有遗漏"的结果——包括查出来但没采纳的。**

方法：v2.2 起草后，另起两个**不知道结论、只负责挑错**的审计者，各自独立审一个对象，要求给出"若忽略会致命"的三条，并明确禁止写赞美。审计稿在包外（`aisq_audit/`），结论逐条判定是否吸收，记录在此。

---

## 审计轮次

| 轮 | 审计者视角 | 审的对象 | 产出 |
|---|---|---|---|
| R1-A | 产业研究 / 投资尽调负责人 | 14 维维度总纲是否真的够用 | 9 条发现 |
| R1-B | 证据核查 / 引用严谨性 | 引用到句机制与门禁可执行性 | 10 条发现 |
| R2 | 作者自审（吸收后回扫） | 修补是否引入新漏洞、文档是否自相矛盾 | 见 §3 |

## 1. R1-B（引用机制）发现与处置

| # | 发现 | 判定 | 落点 |
|---|---|---|---|
| B1 | 门禁九条引用断言有 4 条对出厂模板**恒真**；定位正则允许"正文/摘要"等章名，"行里出现'正文'"即通过 | **已吸收** | `check_citation` 改为逐列解析；定位必须是**位置**（页/段/条/表行/时间戳/查询），章名不再合格；抽样必须真有 ≥2 行填写；可追溯率改为**脚本计算**并与声明比对 |
| B2 | `verified_by` 是自报，无快照无哈希，`unverified` 是合法值 | **已吸收** | `citation.json` 增 `snapshot{file,sha256,captured_at}` 与 `quote_sha256`；新增 `scripts/verify_citations.py` 做 `quote ⊂ snapshot` 子串机检 + 哈希校验；无快照即无法通过 sentence 轨道 |
| B3 | 数据源在 schema 里没有 `query` 这一 kind，"句子"这个单位本身是错的 | **已吸收** | 引入三条轨道 `evidence_track`：`sentence` / `reproducible_query`（dataset+version+filter+fields+period+row_key+unit+tolerance）/ `accountable_provenance` |
| B4 | `context` 无约束，真句子 + 错范围可 100% 通过 | **部分吸收** | 模板强制"上下文"列 + 抽样必查上下文；机检只能查存在与长度，**断章判定仍需人工抽样**（残余风险，见 §4） |
| B5 | `grade` 给"来源"定级，不判"这句是否支持这条" | **部分吸收** | 媒体/公众号禁止评 A/B；"逐句支持度"无法机检，留给 `citation_auditor.md` 的强度漂移检查 |
| B6 | `chain_length` 与 `grade` 解耦，写 ≥2 反而不触发回溯 | **已吸收** | 链长 ≥2 强制出现回溯记录；等级规则写明"按最弱一环定" |
| B7 | 付费墙/内部/访谈无位置，"进不进关键结论"无字段 | **已吸收** | `accountable_provenance` 轨道强制 `provenance` / `why_not_public` / `if_false_consequence`；禁止作为 confirmed 结论的唯一依据 |
| B8 | `published_at` 无格式、无生效/废止状态 | **部分吸收** | 政策类强制"文号 + 条款 + 生效日"；废止状态靠人工，未机检 |
| B9 | 可追溯率是作者自报的百分数 | **已吸收** | 脚本算分；声明值不得超过计算值（超 5% 即 FAIL） |
| B10 | 抽样"随机抽 3 条"不可复现、无审计人 | **部分吸收** | 模板要求记录抽样类型与结果；随机种子与审计人字段未做（成本不划算） |

**R1-B 最重要的一句（已写进设计原则）：**
> 所有能承载"证明"的字段若由被审方填写，而校验器只校验其格式，那么它产出的不是证据，是**背书**。
> 门禁的职责不是"检查有没有填"，而是"检查能不能算"。

## 2. R1-A（维度总纲）发现与处置

| # | 发现 | 判定 | 落点 |
|---|---|---|---|
| A1 | 维度覆盖只验字符串；且 SKILL 正文仍写"六条"而门禁已按七条 → 照文档交付会被判 FAIL | **已吸收** | 全局"六条→七条"（5 处 SKILL + 2 处模板）；门禁改为"≥5 行 D 编号明细"**或**"含 `n/14` + 未查 + 维度编号"的实义行 |
| A2 | D5/D6/D9 在报告里没有章节席位，会被压成别节的一句话 | **已吸收** | 模板新增 §7.2 市场与竞争、§7.3 主体/采购链/利润池；总纲 §6 映射表同步 |
| A3 | 14 维无一以**利润池**为对象 → 能证明"成本低/市场大"，答不出"钱被谁拿走" | **已吸收** | D4 增"利润池：本层毛利、上下游分配、ROIC"；模板 §7.3 增利润池行 |
| A4 | 无权重、无 Go/No-Go 闸门 → 结论必然"机遇与挑战并存" | **已吸收** | D13 增"权重与闸门""反事实与期权"；模板 §1 要求落到 Go/No-Go/条件性 Go + 阈值 |
| A5 | 14 维平铺不产生交叉判断 | **已吸收** | 总纲新增 §8：固定 8 对交叉（性能×成本=性价比、市场×政策=政策依赖度、竞争×供给=供给壁垒…），每对必须带证据或标 `checked-none` |
| A6 | D13 的"反事实/可逆性"写在"需要"栏却从不执行 | **已吸收** | 并入 D13 必答：不行动会怎样、小步试错成本、花多少钱买多少信息 |
| A7 | 新兴产业没有统计口径时，"最低证据"会把结论逼成全部 unknown | **已吸收** | D5 增五级证据降级阶梯（官方统计→披露/招标加总→代理指标→一手访谈→判 unknown 并标"多少钱能买到") |
| A8 | D1 要求前置决策场景不现实（很多调研是"先研究再看能支撑什么"） | **部分吸收** | 保留 D1，但允许"目标未知 → 按最保守假设执行 + §13 声明 + 结论只在哪些决策下成立"；不采用"取消前置"，因为无目标的调研无法定深度 |
| A9 | unknown 不分"不存在 / 要花钱 / 没查"，报告无法回答"要不要再花 10 万补数据" | **已吸收** | 总纲新增 §9：`NOT_EXIST` / `PAYWALL` / `NOT_CHECKED` 三分类与各自决策含义 |

**R1-A 最重要的一句（已写进设计原则）：**
> 维度写对了不等于被验收了。**任何"覆盖"如果只在正文里被声称，而不在验收口被检查，就等于没有。**

## 4. 已知残余风险（不打算在 v2.2 解决，写出来是为了别装作没有）

1. **门禁验结构不验真伪。** 快照机制只解决"引文是否存在"，不解决"来源本身是否可信""这句话是否被正确理解"。后者仍靠 `citation_auditor.md` 的人工抽样。
2. **抽样靠人，且成本真实。** 全查 A 级 + 随机 3 条 B 级，在 20 条引用的报告上约 15–25 分钟。这是刻意保留的成本：把它自动化成"模型自查"等于取消检查。
3. **审计视角仍有盲区。** 本轮只请了"产业研究"和"证据核查"两个视角，没有请法务、财务审计、工程可靠性。**下一个该补的视角是法务（效力/管辖/时效）与财务（口径/舞弊红旗）。**
4. **L1–L4 定档仍依赖人判。** 已把判据改成可判定项（因果图双向边、双向时间证据），但"这张因果图是否成立"无法机检。
5. **评测只有规格，没有基线分数。** 13 个案例定义了"什么算做到"，但尚未用真实 agent 跑出基线通过率——所以"它能挖到多深"目前仍是设计论证，不是实测结论。

---

## 5. 结论

遗漏是查不完的，能查完的是**"我查过哪些、为什么采纳/不采纳"**。

本轮的净收益不是"补了 19 条"，而是两条可复用的判据：

- **验收信号必须能算**，不能只是能填（否则报告通过检查却不通过现实）；
- **覆盖必须在验收口被检查**，不能只在正文被声称（否则"全面"永远是形容词）。

两条都已落到 `quality_gate.py` 与模板里，而不是留在这份文档里。
