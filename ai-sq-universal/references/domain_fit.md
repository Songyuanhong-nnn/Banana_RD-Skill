# 领域适配矩阵 / Domain Fit Matrix

> **本文档替换 v2.0 描述中的"适用于所有领域"。**
> 那句话本身就是一次违规：它是一条绝对化断言（"所有"），而本 Skill 的规则要求绝对化断言必须经过反例检查。
> 反例是现成的——数学证明、审美判断、毫秒级决策，以及任何证据不在公开语料里的问题，
> 用这套框架多半只会产出"看起来有证据链"的错答案。下面给出按证据结构排出的真实适配度。
> **判定成本约 30 秒：找到你的领域行，读对应的"为什么"。**

---

## 1. 一句话判据

**适用 = ① 结论可由可检索的公开证据支撑 ② 答错有代价 ③ 允许花时间。**

| 条件 | 自检问题 | 不满足时的正确处置 |
|---|---|---|
| ① 公开证据可支撑 | 支撑结论的证据是否**已经公开存在**？ | 不适用：标 `needs_human`，只输出"需要什么数据、谁能提供" |
| ② 答错有代价 | 结论若错，是否有人因此受损、返工或作出错误决策？ | 无需本工具：直接快答。没有代价的深挖只是在烧预算 |
| ③ 允许花时间 | 决策窗口是否显著大于一次"检索 + 核验"（分钟级）？ | 不适用：改用低延迟数据链路，本工具追不上 |

三条全满足才进入"强 / 中"。缺一条不是"勉强能用"，而是**换工具**。

判的是**问题的证据结构**，不是问题的学科归属——同样落在"医学"，问指南推荐等级是强适配，
问"我这个剂量该不该减"是不适用。学科名只决定加载哪个领域包，不决定适配度。

## 2. 主表

| 领域 | 适配度 | 为什么 | 缺什么手段 |
|---|:---:|---|---|
| 科学机制调研 (science) | **强** | 结论落在一手层：序列/蛋白库、系统综述、原始论文可互为交叉验证，证伪路径也是公开的（重复实验、独立数据集、缺失突变+回补） | 无硬缺口；只缺一手实验数据，问题沉降到实验参数即须标"需实验验证" |
| 技术选型/协议差异 (technology) | **强** | 三件带坐标的公开物可互相裁定：标准文本 + 源码 tag + 可复现实测；结论能绑定版本号，因而可复核、可推翻 | 私有环境的实测：内部压测、真实故障态、生产流量形态 |
| 历史事件与史料分歧 (history) | **强** | 证据是一手档案与考古实物，学科已把"史料批判"固化为方法（来源、动机、传承链）；分歧本身以两说并陈的形式公开存在 | 未数字化/未开放的档案；实物复检（碳十四、器物比对）能力 |
| 法律条文适用 (law) | **中** | 强在法源检索：条文、司法解释、指导案例都带文号与生效日期，可精确引用；弱在个案事实认定——证据能力、过错、因果只在案卷与当事人陈述里，不在公开语料 | 证据开示/阅卷、当事人陈述、执业律师的适用判断 |
| 金融/商业归因 (finance, business) | **中** | 强在公开披露的口径拆解：年报分部、监管公告、招股书足以还原 sell-in/sell-through 与非 GAAP 调整；弱在归因所需的内部数据——成本结构、渠道库存、客户留存不在披露范围 | 内部管理报表、渠道库存、CRM/留存数据、非公开尽调 |
| 政策评估 (policy) | **中** | 强在文件原文 + 实施细则 + 官方统计可三方核对；弱在效果归因需要反事实（DID / RCT / 断点），而执行强度、基层行为、同期政策捆绑只能靠一手调查 | 反事实设计所需面板数据、基层执行记录、未公开的考核指标 |
| 医学临床决策 (medicine) | **弱** | 证据侧可梳理（指南、系统综述、说明书），但决策变量是个体的：合并症、肝肾功能、基因型、正在服用的药、过敏史——这些构成本次就诊的患者数据，检索不到 | 患者病史/检验/影像、执业医师的查体与处方权 |
| 实验/工程故障定位（私有系统） | **弱** | 检索只能产出候选假设；故障定位的本质是把假设与一手测量对上（日志、最小复现、版本差分、二分）。没有测量，各假设之间就没有可比较的权重，排序只是叙事 | 一手测量：日志、监控指标、最小复现、变更 diff |
| 实验/工程故障定位（开源公开项目） | **中** | 当故障发生在公开项目、issue/源码/复现步骤都在公开域时，"一手测量"其实也可检索（版本 tag、已知 issue、CI 记录、changelog）。此时限制不是证据可得性，而是**能否复现** | 复现环境；特定版本/配置的实测 |
| 多主体博弈/策略互动 | **弱** | 文献能提供历史对局与已发表均衡作为参照，但结论取决于对手的 payoff 与信息集——那是当前局面的私有参数；拿不到就等于没有模型 | 对手收益矩阵、信息集、承诺能力；博弈论建模 |
| 数学/形式化证明 | **不适用** | 命题真值由推导决定。检索只能回答"有没有人证过"，不能替你证；证据链机制在这里无事可做 | 形式化推导、证明检查器（Lean / Coq） |
| 创意/审美/价值判断 | **不适用** | 没有可证伪的 claim，也就没有"证据等级"。强行做证据链，多半只是把偏好包装成结论 | 作者意图、受众与场景；决策权在委托方 |
| 实时/高频决策 | **不适用** | 本工具流程最小时延是分钟级（检索 + 核验 + 成答），而这类决策窗口是秒或毫秒；报告写完，结论已过期 | 低延迟数据链路与自动执行；与默认 600s 预算相差数个量级 |
| 私人/内部/未公开数据 | **不适用** | 结论的证据全在未公开语料里，检索的边际收益为零；继续追多半只是生成"看起来像证据"的猜测 | 数据访问权、NDA 下的访谈、内部系统权限 → 标 `needs_human` |

判定口径对齐各领域包声明的六件事（`entity_levels` / `structure_semantics` / `authoritative_sources` /
`evidence_grades` / `counterexample_rule` / `high_risk`），逐包见 [domain_packs/](../domain_packs/)。

## 3. 强适配：这三个领域最容易被本框架误导

强适配 ≠ 不会错，只说明错误是可被规则拦住的。以下是该领域特有的失准机制，也是报告必须显式呈现的项。

### 3.1 科学机制调研 (science)

- **类别 → 实例**：物种级"致病"结论套到菌株，是最常见的层级错误——同一物种的共生株与致病株结论可以完全相反（E. coli K-12 vs O157:H7）。`entity_levels` 校验只有在报告强制写 `scope` 与 `qualifier` 时才生效；省略 scope，校验就是空转。
- **证据跨级外推**：in vitro → 动物 → 人体 → 人群，每一级都要重新取证。"机制已清楚"既不等于"在该层级成立"，也不等于"有临床意义"。

### 3.2 技术选型/协议差异 (technology)

- **文档 ≠ 实现**：官方文档声称支持某特性，与源码/实测行为可以不一致，而且这种不一致通常不写进 changelog。跳过"核对源码或最小实测"这一步，输出就退化成"文档说支持 → 结论说支持"。
- **版本与环境共同定义结论**：未绑定 tag/commit 的技术结论默认 C 级；跨硬件、跨负载形态的基准数字不可直接比较。技术结论的有效期 = 版本 × 环境，缺一即过期。

### 3.3 历史事件与史料分歧 (history)

- **史料沉默**：未被记载 ≠ 不存在。否定性结论（"没有发生""不存在"）必须先估史料存留概率与记录者动机，否则框架会把"搜不到"直接写成"不存在"——这是空缺被升格成关键结论的最短路径。
- **层累建构**：晚出文献对早事的"补写"，在检索结果里与同时代记载并列出现。不剥离层累，越晚、越"完整"的记载反而权重越高。

## 4. 中等适配：强在哪一半，弱在哪一半

中 = **证据的一半在公开语料里，另一半在别处**。用对的一半能显著降低专业者的准备成本；
把另一半当已知，就会越过边界直接产出错误建议。

### 4.1 法律条文适用 (law)

- **命中的规范未必是本案应适用的规范**：条文检索容易命中已废止版本、命中一般法而漏掉特别规定，或把法学期刊的学理当成法律规则。三者后果相同——引用的规范根本不是现行有效规则；所以"标注版本与生效日期 + 先检索特别规定 + 学理与条文分列"是必需步骤，不是格式要求。
- **个案事实不在射程内**：证据能力、过错、因果、时效都要靠案卷与当事人陈述，这些不在公开语料里。报告必须停在"需结合案卷与律师判断"；越过这条线继续写，产出的就是法律意见。

### 4.2 金融/商业归因 (finance, business)

- **口径与样本期**：收益率、增长、份额各有多种口径（名义/实际、含费/不含费、sell-in/sell-through、organic/inorganic、按收入/按 GMV）。不先定口径与分母就横向比较，数字本身没有含义。
- **幸存者偏差与过拟合**：只统计存续公司/成功门店会系统性高估行业回报；无样本外检验的回测是反例，不是证据。用单一龙头推断行业规律，是把选择偏差当结论。

### 4.3 政策评估 (policy)

- **意图 ≠ 执行**：文件写了不等于落地。预算、考核指标、基层裁量才是执行，而这些恰恰不在文件里；只读文件会把"政策目标"复述成"政策效果"。
- **反事实缺失**：没有对照就只能写"同期变化"，不能写"导致"。叠加试点地区非随机（选择偏差）与指标一旦成为考核目标即被操纵（Goodhart），看起来漂亮的评估数字也可能整体作废。

## 5. 弱适配与不适用：不算滥用的用法

弱 / 不适用的正确响应不是"更用力地检索"，而是**换一个问题问**。下表给出每种情况的降级路径与越界信号。

| 领域 | 不算滥用的用法（降级路径） | 越界信号（应停手） |
|---|---|---|
| 医学临床决策 | 只做三件事：梳理指南与系统综述的证据等级、列出该问题的标准治疗选项与禁忌、整理相互作用清单供医师核对；输出标注"不构成诊疗建议" | 给出剂量、疗程、是否停药、是否手术的结论；仅凭症状描述推断诊断 |
| 实验/工程故障定位（私有系统） | 只做假设生成：产出按可能性排序的故障树，并为每条假设配一个能证伪它的测量；不宣称根因 | 写出"根因是 X"却没有一手测量支撑；把相似历史案例当本次故障的证据 |
| 实验/工程故障定位（开源公开项目） | 可用：以公开 issue/commit/changelog 建候选集，同时绑定版本与配置；结论写成"该版本在该配置下的已知缺陷"，而非"你的系统根因是 X" | 越过复现直接断言根因；把上游已修版本的问题当当前问题 |
| 多主体博弈/策略互动 | 只做参照系：历史对局、已发表的均衡分析、对手的公开承诺与既往行为；并列出建模所需的私有参数 | 给出"我方应出价 X / 应先发 Y"这类策略建议；假设对手 payoff 后当已知条件 |
| 数学/形式化证明 | 只做定位与表述澄清：定理叫什么、出处、常见误用；给出证明思路的文献线索 | 输出"证明如下"却未经形式化校验；用检索到的相似定理替代推导 |
| 创意/审美/价值判断 | 只做素材与先例：同类作品的处理方式、编辑规范、评审标准；结论交回委托方 | 判决"这是好设计 / 应该这样写"；把偏好包装成证据链结论 |
| 实时/高频决策 | 只做离线背景：制度、机制、历史案例；实时信号改用专用数据链路 | 用分钟级调研替代秒级信号；对"现在该买/该卖"给结论 |
| 私人/内部/未公开数据 | 标 `needs_human`，写清"需要什么数据、谁能提供、拿到后怎么用"；可做方法设计与取数方案 | 用公开信息反推未公开数字并当事实；虚构内部数据来源 |

## 6. 三条硬边界

1. **不替代专业判断**。输出是证据整理与争议呈现，不是意见。法律意见、诊疗方案、投资建议、安全放行的责任主体是持证人，不是这份报告。
2. **不产生一手数据**。证据强度上限 = 已公开材料的上限。凡需要测量、访谈、阅卷、实验、内部报表的问题，正确输出是 `needs_human` + 取数路径，不是更用力的检索。
3. **不解决演绎问题**。数学证明、代码正确性、逻辑一致性靠推导与检查器。检索能提供前提与反例，永不提供证明。

三条边界之内，剩下的都是适配度问题——先查表，比问"这工具能不能用"更快，也更诚实。

## 7. 本表的判定口径（可复核）

| 适配度 | 判据 |
|---|---|
| **强** | 三条件全满足，且该领域的主要一手权威源可公开检索；框架的主要风险是层级/口径混淆，可被规则拦住 |
| **中** | 三条件全满足，但**关键变量有一半必须来自公开语料之外**；合法用途是把公开的那一半做扎实，越界点可明确定义 |
| **弱** | 公开证据只覆盖"背景与假设"，覆盖不了"当前个案的决策行为"；必须降级为背景梳理或假设生成 |
| **不适用** | 至少缺一个条件，且不是预算问题而是结构问题——加时间、加检索也补不上 |
