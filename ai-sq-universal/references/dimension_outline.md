# 调研维度总纲 / Dimension Outline

**这是"完全综合"的骨架。** 它回答一个问题：**调研一个对象时，到底要问哪些面？**

---

## 0. 为什么需要第三套覆盖

Skill 里已有两套覆盖机制，各管一层，不能互相替代：

| 机制 | 覆盖什么 | 回答的问题 |
|---|---|---|
| 九层追问链 | **单个问题挖多深** | 这条因果链到底通不通 |
| 因素九轴 | **单个结果的因素类型** | 影响 Y 的东西有没有整类漏掉 |
| **本总纲 14 维** | **调研对象要回答的问题面** | 客户/决策者会问哪些问题，我答全了吗 |

第三套的必要性：前两套都是"以对象为中心"往下挖，而真实调研是"以决策为中心"铺开——**投资人会问市场多大，工程师会问性能余量，采购会问总拥有成本，法务会问合规边界**。少一维，报告在某一类读者眼里就是残缺的。

**三者关系**：14 维决定"要回答哪些面"；每一维里的具体问题用九层链挖深；影响结果的因素用九轴铺开；最后由 §14 覆盖度声明统一验收。

---

## 1. 选维度 → 逐维答 → 四轮查漏

```
① 判定对象类型 → ② 激活必选维度（其余维度写"为何不选"）
→ ③ 每维逐条回答（必答问题）+ 记录困难与分支
→ ④ 四轮遗漏自检（维度级 / 因素级 / 反例级 / 负空间）
→ ⑤ 饱和判定 → 停止并声明
```

**空维度不许留白。** 写"不适用：该对象无市场交易属性"是结论；留白是漏洞。

## 2. 十四维总表

## 3. 逐维细则

每一维给四件事：**必答问题**（问什么）、**需要什么**（到哪找）、**典型困难**（这里会长出分支）、**最低证据 / 何时判 unknown**。

### D1 目标与决策场景

- **必答**：这份调研支撑哪个决定？决策时点？失败代价？谁会读？要"够用"还是"能上会"？
- **需要**：与委托方的问答、决策流程文件、同类决策的既往案例。
- **典型困难**：目标没写清 → 后面所有维度的深度无法定；目标中途变化。**→ 分支：先做目标澄清，或声明假设并标注"若目标不同则结论应改"**。
- **最低证据 / 判 unknown**：目标必须落成一句可判定的话；无法获得则按最保守假设执行并在 §13 声明。

### D2 定义、边界与口径

- **必答**：对象是什么？**不包含什么**？同名异义有哪些？统计口径（含税/不含税、峰值/持续、名义/实际、出厂/零售）？时间边界？地域边界？
- **需要**：标准定义（国标/行标/学界定名）、监管口径文件、行业惯例说明、厂商术语表。
- **典型困难**：**同名不同物**（"这个市场"指整机还是零部件）、**口径不一致**（两家份额数据不可比）、**边界漂移**（新技术把旧定义撑破）。**→ 分支：口径对齐表 / 同名术语消歧 / 边界敏感性（两种口径各算一次）**。
- **最低证据 / 判 unknown**：口径必须有出处（哪个部门/哪份标准哪一条）；对不上就并列两种口径，禁止混算。

### D3 性能与技术能力

- **必答**：核心指标是哪几个？各自数值与**测试条件**？峰值与持续差多少？技术成熟度（TRL/量产状态）？瓶颈在哪？代际差距？替代技术能否满足？
- **需要**：datasheet、第三方测试报告、招标技术参数、专利、标准符合性报告、用户实测、拆解报告。
- **典型困难**：**厂商口径**（理想条件）、**测试条件不可比**（温度/负载/工况不同）、**只给峰值不给持续**、**无第三方横评**、**参数好但可用性差**。**→ 分支：统一到可比口径 / 找同条件横评 / 补边界条件 / 从失效案例反推真实能力**。
- **最低证据 / 判 unknown**：关键指标至少一个独立来源；只有厂商自述时标 D 级并明示。无测试条件的数据一律不可比。

### D4 经济性

- **必答**：单价？**总拥有成本**（采购+安装+运维+耗材+停机+处置）？成本结构占比？规模效应拐点？盈亏平衡点？价格趋势？汇率/关税/税负影响？
  **利润池**：这一层赚多少毛利？上下游各分走多少？谁在价值链上拿走大头？ROIC/资本回报如何？——**只证明"成本低/市场大"而答不出"钱被谁拿走"，是投决会最常见的杀 deal 理由。**
- **需要**：报价单、招标中标价、年报成本分部、行业成本模型、运维记录、二手交易价、毛利率与分部利润、价值链利润分布。
- **典型困难**：**只报采购价不谈 TCO**、**报价≠成交价**、**规模外推失效**、**隐性成本**（培训、备件、停机）、**口径含税与否**。**→ 分支：TCO 建模 / 折扣率与账期还原 / 敏感性分析（单价×利用率×寿命）**。
- **最低证据 / 判 unknown**：至少两个独立价格来源；成本结构需拆分到可解释粒度。缺运维数据则 TCO 标"下界"。

### D5 市场与需求

- **必答**：规模多大（TAM/SAM/SOM 分别多少）？增速与驱动因素？细分结构？谁在买、买多少、采购周期？需求是刚性的还是补贴驱动的？**金额口径**是出厂值还是终端值？
- **新兴/未成形产业的证据降级阶梯**（没有协会统计、没有第三方数据时，按序降级而不是硬凑）：
  1. 官方统计/协会口径 → 2. 上市公司分部披露或招投标加总 → 3. 海关/用电/用地/招聘等**代理指标**（必须写"代理关系"假设）→ 4. 一手访谈与渠道抽样（标 `accountable_provenance`）→ 5. 明确判 unknown 并给"要多少钱/多久能买到这个数"。
- **定制 / 中试型产品**：统计科目通常只到上位品类（如只到"干燥设备"而无"中试冻干机"），**只给量级 + 并列口径**，不要为了填表编细分数字。
- **需要**：官方统计、行业协会数据、上市公司披露、招投标记录、海关数据、渠道调研、第三方机构报告（注意其商业模式）。
- **典型困难**：**TAM 拍脑袋**（自上而下乘系数）、**统计口径不一**（产值 vs 销售额 vs 出货量）、**政策补贴制造的需求幻觉**、**第三方报告互相抄**、**细分数据不公开**。**→ 分支：自上而下 vs 自下而上交叉验证 / 用招投标与海关数据做硬校验 / 拆出补贴敏感度**。
- **最低证据 / 判 unknown**：规模数字至少两个独立口径且能解释差异；只有一份付费报告时标 C 级并注明其委托方。

### D6 竞争与同行

- **必答**：玩家地图（含退出者）？份额与依据？产品矩阵与定位？定价策略？**benchmark 方法与口径**？专利与标准话语权？护城河是什么？同行怎么做同一件事？
- **一次性 / 定制设备的分支**：D6 默认假设"存在共享测量协议 + 一批可比玩家"，而单台定制设备往往**三样都没有**（没有按型号的份额、没有独立同条件横评、也没人为三台设备的横评付费）。此时 D6 的正确形态不是"找横评"，而是：
  1. **证明横评不存在**（写清问过谁、为何没有——商业机密 / 只接受现场测 / 从未做过满载测试）；
  2. 建**可比性台账**（指标 × 设备 × 是否可比，不可比的直接标 ❌，不留空格）；
  3. 把"不可比"转成**合同条款**：统一测试条件写进 SAT 验收 + 性能罚则——这是把不确定性转成可执行约束，比多写一句"建议进一步验证"有用得多。
- **需要**：财报与招股书、产品手册、专利族、招标中标记录、第三方测评、招聘信息（反推技术栈）、渠道价。
- **典型困难**：**份额数据来源不明**、**benchmark 只挑对自己有利的指标**、**幸存者偏差（只看到活着的玩家）**、**跨代际比较**（拿旧型号比新型号）。**→ 分支：自建可比矩阵 / 找退出与失败案例 / 统一测试条件 / 拆"参数领先"与"成本领先"**。
- **最低证据 / 判 unknown**：份额必须有来源与方法；无法获取则给"玩家与其定位"，明确不给份额数字。

### D7 供应链、产能与交付

- **必答**：关键投入有哪些？单一来源风险？产能与利用率？交期？库存与在途？上游议价能力？地缘/物流约束？
- **需要**：供应商公告、产能投放计划、海关与物流数据、行业供需平衡表、企业调研纪要。
- **典型困难**：**产能"规划"当"已投产"**、**良率不公开**、**关键材料被单一供应商卡住**、**交期随订单波动**。**→ 分支：区分规划/在建/达产 / 找替代供应路径 / 用交期反推紧张度**。
- **最低证据 / 判 unknown**：产能须区分"名义/有效/达产"；未披露良率则结论限定在名义产能。

### D8 政策、法规与标准

- **必答**：准入要求？强制标准？合规成本？补贴/税收优惠？**生效时间表**？中央与地方差异？执法强度？未来修订方向？
- **需要**：法律法规数据库、部门规章与规范性文件（**文号 + 条款**）、标准全文、征求意见稿、执法案例、地方实施细则。
- **典型困难**：**征求意见稿当生效文件**、**国家标准与行业标准冲突**、**地方执行尺度差异**、**旧法未废止**、**过渡期安排被忽略**。**→ 分支：效力核验（现行有效？）/ 特别法优先 / 地方差异对照 / 过渡期时间轴**。
- **最低证据 / 判 unknown**：必须给文号、条款号、生效日；只有新闻转述不算（D 级）。

### D9 主体、激励与采购链条

- **必答**：谁决策、谁使用、谁付费？采购流程与门槛？关键 KOL 与渠道？各方激励与阻力？替换成本？
- **需要**：组织架构与职责文件、采购制度、招标公告、渠道政策、访谈纪要、人事变动。
- **典型困难**：**使用者与付费者分离**（好产品卖不动的原因）、**采购门槛隐性**（资质/入围）、**渠道加价结构不透明**。**→ 分支：画决策链与付费链 / 找入围条件 / 拆渠道加价**。
- **最低证据 / 判 unknown**：决策链需有制度或公告支撑；仅凭常识推断要标"假设"。

### D10 时间、阶段与路线图

- **必答**：历史怎么演化到现在？当前处于哪个阶段？下一个拐点靠什么触发？里程碑时间表？**时滞多久**？技术/政策/产能的时间对齐吗？
- **需要**：时间序列数据、路线图白皮书、政策时间表、企业投产计划、版本发布记录。
- **典型困难**：**把长期趋势外推到短期**、**里程碑普遍延期**（历史兑现率）、**时滞被忽略**（投放到见效之间）。**→ 分支：查历史兑现率 / 建时间轴对齐 / 做早/中/晚三情景**。
- **最低证据 / 判 unknown**：时间表须有一手来源（公告/文件）；无则给"区间 + 触发条件"而非单点日期。

### D11 风险、失败模式与反例

- **必答**：会怎么失败？谁已经失败过（**退出者清单**）？技术/商业/政策/供应风险各是什么？触发阈值？最坏情况？**反例能否推翻主结论**？
- **需要**：破产/退出/召回/事故记录、诉讼与处罚、失败项目复盘、技术失效报告、历史泡沫案例。
- **典型困难**：**只研究成功者**、**失败信息被删除**、**风险写成套话**（"存在一定风险"）。**→ 分支：专门检索退出与失败 / 找临界失败案例 / 给触发条件与早期指标**。
- **最低证据 / 判 unknown**：至少一个具体失败案例；写不出触发条件就等于没做风险管理。

### D12 证据质量与争议

- **必答**：每个关键数字来自谁、什么方法、什么时间？多源冲突在哪？谁有利益冲突？哪些是转述？哪些已过时？
- **需要**：原始报告而非二手摘要、方法学附录、样本说明、作者背景、利益披露。
- **典型困难**：**二手转述层层放大**、**付费报告的委托方偏差**、**样本不可比**、**数据被选择性呈现**。**→ 分支：回溯一手 / 并列冲突 / 按最弱环节定级**。
- **最低证据 / 判 unknown**：关键数字须能追到一手或标 C/D；冲突必须列表呈现，禁止取平均。

### D13 决策含义与替代方案

- **必答**：所以该做什么？有哪些替代方案（含"什么都不做"）？权衡是什么？**什么条件下结论反转**？需要监控哪些指标？
  **权重与闸门**：14 维里哪几维对本次决策是决定性的（给权重或排序）？**Go / No-Go 的阈值是什么**？达不到阈值时是否明确说"不进入"？——没有权重的 14 维会产出"机遇与挑战并存"式结论，等于没判断。
  **反事实与期权**：不行动会怎样？先小步试错（试点/小规模采购/期权）要多少钱、能买到什么信息？
- **需要**：D1 的决策标准、各方案对比矩阵、敏感性分析、可逆性评估。
- **典型困难**：**只给信息不给含义**（报告读完不知道干啥）、**单方案论证**、**忽略"不行动"选项**。**→ 分支：生成替代方案 / 设反转条件 / 定监控指标**。
- **最低证据 / 判 unknown**：必须写出"结论在什么条件下不成立"；写不出说明结论本身不稳。

### D14 未解、负空间与下一步

- **必答**：还有哪些该问没问？哪些数据拿不到？**按常识应该存在但没找到的因素/数据是什么**？下一步查什么、谁来验证？
- **需要**：本报告的 gaps 清单、轴覆盖表、未查维度、外部审计意见。
- **典型困难**：**用"限于篇幅"掩盖没查**、**不写负空间**。**→ 分支：负空间清单 / 补查计划 / 降级使用建议**。
- **最低证据 / 判 unknown**：必须成文列出；这是报告可信度的最后一道闸。

## 4. 维度选择器（按对象类型激活）

| 对象类型 | 必选维度 | 可选 | 典型报告重点 |
|---|---|---|---|
| **产业方向** | D1 D2 D5 D6 D8 D10 D11 D13 | D3 D4 D7 D9 | 市场空间、竞争格局、政策窗口、拐点判断 |
| **设备/装备** | D1 D2 D3 D4 D6 D5 D11 | D7 D8 D9 | 性能可比、TCO、同行横评、市场规模 |
| **技术方案/选型** | D1 D2 D3 D4 D12 | D6 D10 D13 | 能力边界、总成本、可替代性、验证方法 |
| **公司/标的** | D1 D2 D4 D5 D6 D11 D13 | D7 D8 D9 | 商业模式、财务质量、竞争位、风险 |
| **政策/法规** | D1 D2 D8 D9 D10 D13 | D5 D11 | 适用范围、生效时间、执行差异、合规路径 |
| **法律问题** | D1 D2 D8 D11 D13 | D9 | 请求权基础、例外、时效、救济 |
| **科学机制** | D1 D2 D3 D12 D14 | D10 D11 | 机制链、证据等级、争议、边界 |
| **历史事件** | D1 D2 D9 D10 D11 D12 | D8 | 史料层级、因果、分歧、反例 |

**规则**：未激活的维度必须在 §14 写"为何不选"。写不出理由 = 你只是没想到。

## 5. 四轮遗漏自检（"重复去查"的机制）

单轮自查几乎总会漏，所以强制四轮，每轮问法不同：

| 轮 | 问法 | 具体动作 | 通过条件 |
|---|---|---|---|
| **R1 维度级** | 14 维我答了几维？ | 逐维勾选：已答 / 不适用（理由）/ 未查 | 无"未查"，或未查项明确列入负空间 |
| **R2 因素级** | 每维的因素按九轴铺开了吗？ | 对每维主导因素过九轴（时间/层级/主体/资源/制度/信息/技术/环境/反馈） | 每轴有因素或"空+理由" |
| **R3 反例级** | 我的每个强结论，有没有找过反例和失败者？ | 15 个复杂度模式逐个比对 + **退出者/失败案例专项检索** | 每个 `dominant` 结论有反例检索记录 |
| **R4 负空间级** | 按常识该有、但我没找到的是什么？ | 列 3–5 条，并判断"是数据不存在"还是"我没查到" | 成文列入 §14；区分二者 |

**饱和规则**：连续两轮自检**零新增**候选维度/因素/反例，方可声明"已饱和"。一轮零新增只是"这轮没找到"。

## 8. 交叉判断：维度两两相乘才是结论

14 维平铺只会产出清单，**真正的判断几乎都来自两维相乘**。至少固定检查这 8 对：

| 交叉 | 相乘后回答的问题 | 判错的后果 |
|---|---|---|
| D3 性能 × D4 成本 | 性价比：单位性能的成本，谁更优 | 只比参数或只比价格，得出反向结论 |
| D5 市场 × D8 政策 | 政策依赖度：需求有多少来自补贴/准入 | 把政策红利当真实需求 |
| D6 竞争 × D7 供给 | 供给壁垒：新进入者能否拿到产能/料 | 高估可进入性 |
| D4 成本 × D11 风险 | 单位经济性在坏情景下是否仍成立 | 好年景模型，坏年景崩 |
| D5 市场 × D9 采购链 | 可达性：能触达的客户占 TAM 多少 | 把"总市场"当"可卖市场" |
| D6 竞争 × D9 主体 | 渠道与决策链是否被在位者锁死 | 产品好但进不去 |
| D10 时间 × D1 目标 | 决策时点与技术/政策拐点是否对齐 | 早一步或晚一步都亏 |
| D11 风险 × D10 时间 | 风险暴露窗口与退出窗口是否重叠 | 想退出时已无流动性 |

**规则**：每个交叉结论必须带一条证据；写不出就标 `checked-none` 并说明为什么这组交叉不适用。

## 9. unknown 必须分类（否则无法决定"要不要再花钱补数据"）

报告里每个 unknown 都要带类型，三选一：

| 类型 | 含义 | 决策含义 |
|---|---|---|
| `NOT_EXIST` | 该数据不存在或不可能获得 | 换问题，别花钱 |
| `PAYWALL` | 存在但要付费/内部权限/人脉 | 可用预算与时间换 |
| `NOT_CHECKED` | 能查但我这轮没查 | 最不可接受，必须说明为何没查 |

只写"未知"而不分类，读者无法回答"**再花 10 万能不能买到这个答案**"——而这恰恰是调研报告最该回答的问题之一。
