# 复杂度模式速查｜多因素推理工具箱

**用途**：九层追问链（定义→…→前沿）是纵向钻取，保证"一条线上问得够深"，但不保证**因素集齐全**、**交互查过**、**异质性定位过**、**反馈与时滞想过**。本文件补齐横向：15 个必须主动比对的结构模式，加 L1–L4 定级判据、9 轴完备性自检。进入 complexity_level ≥ 2 时读。

**读法**：按症状抽取适用模式，不要 15 条全过（那是形式主义）。但 **#1 混杂、#5 对撞、#6 Simpson、#9 反馈、#14 选择** 五条默认强制过——它们最常被漏，且漏了会把结论**方向**搞错，不只是精度问题。

**每条格式**：定义 → 如何识别（文献/数据里长什么样）→ 必须追问（能把它逼出来的具体问法）→ 检索线索（搜什么词）→ 常见误判（把它认错的典型方式）。

---

## 一、十五个模式

**1. 混杂 confounding（共同原因）**
- **定义**：A 与 B 相关，但两者都被第三个变量 C 驱动，且 C 在样本中分布不均；C 不进模型时，A→B 的强度被高估、低估甚至反号。
- **如何识别**：只有双变量相关或"控制变量"极少的回归；效应量异常大且无机制解释；同一关系在不同国家/时期/人群方向不同；加入一组协变量后效应急剧变化却无敏感性分析。
- **必须追问**：还存在哪个共同原因能同时解释 A 和 B，且它在样本中分布不均（按收入、年龄、地区、诊断批次、行业周期）？它被测量了吗？没测的话作者靠什么识别（工具变量 IV、双重差分 DiD、断点回归 RDD、负对照 negative control）？都没有 → 结论上限只能是"相关"。
- **检索线索**：`confounding` `unmeasured / residual confounding` `sensitivity analysis` `E-value`；再查 limitation 段与基线表是否失衡。
- **常见误判**：把"控制了性别年龄"当成控制了混杂；把**中介**当混杂一起控制（over-adjustment，会抹掉真实效应）；把**对撞**当混杂（控制它反而制造偏倚，见 #5）。

**2. 中介 mediation（机制在中间）**
- **定义**：A 对 B 的作用经由 M 传递；M 位于 A 与 B 的因果链上，不是共同原因。
- **如何识别**：机制叙述出现"通过…实现/借助…传导"；加入 M 后 A 的效应大幅衰减；有 A 先于 M、M 先于 B 的时序证据。
- **必须追问**：M 与 B 的先后真被观测到，还是同一时点的横断面测的？同时测则"A→M→B"与"B→M→A"在数据上不可区分，作者凭什么定向？M 是否只是 A 的另一种测法（构念重叠）？中介比例是在什么序贯可忽略性假设下算的？
- **检索线索**：`mediation analysis` `indirect effect` `proportion mediated` `causal mediation` `path model`。
- **常见误判**：横断面回归里把相关链当中介；"控制 M 后效应消失，所以通过 M"——也可能是 M 是 A 的代理，或 M 与 B 另有共同原因。

**3. 调节 / 效应修饰 effect modification**
- **定义**：A 对 B 的效应在不同层（性别、年龄、地区、制度、时期、剂量档）方向或幅度不同；总体平均效应可能不代表任何一层。
- **如何识别**：分层结果与总体不一致；森林图亚组异质性大（I² 高、交互项显著）；原文写"总体有效但某亚组无效/有害"；不同研究结论相反但人群构成不同。
- **必须追问**：效应在**哪一层反号**、反号幅度多大？分层边界是事先定的还是事后挑的（post-hoc 亚组 = 多重比较，需校正）？每层样本量够不够（看 CI 宽度而非点估计）？调节变量是否与时间/地点共变（所谓"调节"其实是被时代混杂）？
- **检索线索**：`effect modification` `subgroup analysis` `interaction term` `heterogeneity` `I²` `forest plot`。
- **常见误判**：把探索性亚组分析当确证；把调节与中介混为一谈（调节改变效应大小，中介解释效应路径）；小样本导致的"无差异"读成"该层无效"（功效不足）。

**4. 交互 interaction（非可加）**
- **定义**：两因子的联合效应不等于各自效应之和（加性尺度）或之积（乘性尺度）；存在 synergy 或 antagonism，模型不放乘积项就识别不到。
- **如何识别**：单因子研究都只有弱效应，组合起来却明显；或两个各自有效的措施合用反而互相抵消（替代/挤出）；剂量-反应曲线在另一因子不同水平下形状不同。
- **必须追问**：做过联合暴露分层或乘积项检验吗，还是只"各自校正主效应"（那样天然看不见交互）？交互在加性还是乘性尺度上（同一份数据在一种尺度有交互、另一种尺度可能没有）？联合暴露的人数够不够（罕见组合下交互检验功效极低，"未检出"≠"不存在"）？
- **检索线索**：`interaction` `synergy / antagonism` `joint effects` `additive vs multiplicative` `RERI`。
- **常见误判**：两个主效应都显著就说"有交互"；把加性尺度与乘性尺度的结论互换；把功效不足的阴性交互检验当作"无交互"证据。

**5. 对撞 collider / Berkson bias**
- **定义**：C 同时是 A 与 B 的结果。只研究 C=1 的样本、或按 C 分层，会人为造出 A 与 B 的关联（多为负相关），或掩盖真实关联。
- **如何识别**：样本已被筛选（住院病人、已上市企业、通过审批的项目、被报道的案例、进入随访者）；模型"控制"了一个明显位于因果链下游的变量；相关方向与机制预期相反且只在特定子样本出现。
- **必须追问**：入选条件本身是不是 A 和 B 的共同结果（住院/上市/获批/发表/存活）？被控制的变量在因果图上位于 A、B 之前还是之后？去掉筛选条件后关联还在吗？
- **检索线索**：`collider bias` `selection bias` `Berkson's paradox` `ascertainment bias` `index event bias` `conditioning on a descendant`。
- **常见误判**：以为"控制得越多越干净"——控制对撞是**引入**偏倚；把筛样本造的伪相关当发现（"住院病人中两病负相关"）；只审总体不审入选机制。

**6. Simpson's paradox**
- **定义**：总体与分层后的效应方向相反，原因是分组变量（通常是混杂）在组间分布极不均，合并时被权重大的一方主导。
- **如何识别**：合并数据与分地区/分性别/分时段结果方向相反；各组样本量差异巨大且基线率差异大；典型表述"总体改善，但每一组都在恶化"。
- **必须追问**：分组变量各组权重是多少？分层后每层方向是否一致、各层 CI 多宽？合并效应用的是加权平均还是被最大组决定？要回答的是"对个体"还是"对总量"（两者该用不同的率）？
- **检索线索**：`Simpson's paradox` `aggregation paradox` `standardization` `weighting` `pooled vs stratified`。
- **常见误判**：以为一分层就能推翻总体（小样本分层可能只是噪声）；用总体率回答个体问题（下一步就掉进 #7）。

**7. 生态谬误 ecological fallacy**
- **定义**：用群体层面的相关性推断个体层面；群体平均掩盖群内异质性，群体属性也不能还原成个体属性。
- **如何识别**：证据单位是省/国/企业/年度汇总，结论却在说"个人/患者/员工会…"；个体层数据从未被观测；群内方差很大而结论只用了群均值。
- **必须追问**：**证据的单位**与**结论的单位**分别是哪一层，是否同一层？群内相关 ICC 有多大？拆到个体层后关联还在吗？有无跨层效应（群体属性独立影响个体，不经过个体自身属性）？
- **检索线索**：`ecological fallacy` `cross-level bias` `aggregation bias` `multilevel model` `ICC` `contextual effect`。
- **常见误判**：用国家 GDP 与预期寿命的相关推个体健康；把地区发病率高当成"该地居民个体风险高"（可能是人口构成或诊断可及性）；把企业平均结论套到单个企业。

**8. 阈值与非线性 threshold / nonlinearity**
- **定义**：效应不是线性的；剂量-反应存在平台、阈值、U 形/J 形或饱和，线性系数只是某个区间的局部平均。
- **如何识别**：只讨论极端值上的差异；把连续剂量二分成高/低再比较；不同研究用的剂量范围不同而结论相反；曲线低剂量平坦、高剂量陡升。
- **必须追问**：函数形式检验过吗（限制性样条 RCS、分段回归、GAM），还是直接假定线性？阈值估在哪一点、置信区间多宽、有几个断点？阈值两侧的样本够不够密（否则阈值只是插值）？剂量是外生给的还是自选的（病情重→用药多，反向因果会伪造剂量-反应）？
- **检索线索**：`dose-response` `nonlinear` `spline` `threshold` `tipping point` `U-shaped / J-shaped` `saturation`。
- **常见误判**：用线性系数描述阈值关系；把二分后的显著性当成"存在阈值"；忽略剂量自选造成的反向因果。

**9. 反馈回路 feedback loop**
- **定义**：B 反过来影响 A（正反馈放大、负反馈稳定），变量间是联立关系而非单向因果；横断面证据在结构上看不到它。
- **如何识别**：研究对象是显然有回路的系统（价格↔供需、流行度↔质量、监管↔规避、融资↔估值）；作者用同期相关论证方向；效应随时间放大或自我修正；预测反复系统性偏离。
- **必须追问**：横断面/单期数据凭什么定方向（时间先后、外生冲击、工具变量、自然实验）？回路增益是否 >1（>1 发散、<1 收敛到均衡）？观测窗口是否覆盖至少一个完整回路周期（短窗口会把反馈看成单向）？变动 A 之后，B 的回传要多久？
- **检索线索**：`feedback loop` `simultaneity` `reverse causality` `endogenous regressor` `system dynamics` `stock and flow`。
- **常见误判**：把均衡态观测当因果方向；用短面板论证长期反馈；只看回路的一半就写成"A 导致 B"。

**10. 时滞 lag / 累积暴露 cumulative exposure**
- **定义**：原因与结果之间有时间间隔；起作用的可能是累积暴露（剂量×时长）、峰值暴露或某个关键窗口期，而非观测时点的瞬时值。
- **如何识别**：结论对"用哪一年的暴露"极敏感；用急性暴露研究推断慢性效应；不同研究矛盾但暴露窗口不同；效应在暴露结束后很久才出现。
- **必须追问**：暴露到结局隔了多久，这个长度按机制定还是按数据可得性定？用的是累积、峰值还是关键窗口？滞后改成 1/3/5 年，结论是否翻转？长时滞下如何排除反向因果（结局的早期征兆已改变暴露）？观测期够不够长到让效应显形（右删失）？
- **检索线索**：`lag effect` `latency / induction period` `cumulative exposure` `distributed lag model` `critical window`。
- **常见误判**：用同期数据推长时滞效应；把"尚未观测到"写成"无效应"；把时滞造成的错位当成混杂。

**11. 路径依赖与锁定 path dependence / lock-in**
- **定义**：早期偶然事件经 increasing returns、转换成本、网络效应固化，后续路径被约束；当前状态不能只用当前条件解释。
- **如何识别**：解释现状全靠"当前最优/最有效率"叙事，但历史上曾有多种可行分支；标准/格式/制度高度集中且迁移成本高；同类主体同期分化，却能用更早的不同起点解释。
- **必须追问**：这个状态是"当前效率"选出来的，还是"早期一次事件 + 正反馈"锁定的？转换成本多高、由谁承担？回到分叉点，其他路径当时**是否真的可行**（反事实）？锁定是否正在松动（外部冲击、替代技术、规则改写）？
- **检索线索**：`path dependence` `lock-in` `increasing returns` `critical juncture` `switching cost` `network externality`。
- **常见误判**：把所有历史影响都叫路径依赖（不可证伪）；用幸存者偏差解释分化（见 #14）；假定锁定永久，忽略解锁信号。

**12. 多因一果 / 一因多果 / 等效路径 equifinality**
- **定义**：同一结果可由多条不同路径达成（equifinality），同一原因也可导致多个结果（multifinality）；单一原因通常既不必要也不充分，只是某个充分原因集里的一环（INUS 条件）。
- **如何识别**：不同案例/研究指向不同原因且各自都成立；文献写"机制仍有争议"但每条机制都有支持；同一原因在不同情境下导致不同结果。
- **必须追问**：这些原因是"须全部具备"（合取 conjunctural）还是"任一即可"（析取/等效）？单个原因的必要性与充分性分别是什么（都不是 → 只能写"促进/抑制"）？是否已识别出一个充分原因集？不同路径是否对应不同子群（路径异质性）？
- **检索线索**：`equifinality` `multifinality` `INUS condition` `sufficient component cause` `QCA` `conjunctural causation`。
- **常见误判**：把"多因"写成不区分必要性/充分性/促进性的清单；把相关性最强的因子当主因（未做必要性检验）；忽略"某因子只在其他条件存在时才起作用"。

**13. 测量代理误差 proxy / measurement error**
- **定义**：观测指标不是目标构念（construct），只是代理；代理既有测量误差，误差还可能与暴露或结局相关（差异误差 differential error），从而制造、放大或反转效应。
- **如何识别**：关键概念只用单一指标代表（GDP 代发展、被引数代影响力、评分代质量、住院率代发病率）；指标定义在样本内或时间上变过；同一构念的不同来源数值差很大。
- **必须追问**：这个指标覆盖了构念的哪部分、漏了哪部分？误差是随机的还是系统的（非差异误差通常稀释效应，差异误差可反转）？换一个代理指标结论是否稳健？指标口径（定义、阈值、统计边界、修订版）在研究期内变过吗？
- **检索线索**：`construct validity` `measurement error` `proxy variable` `misclassification` `differential vs non-differential` `口径变化` `数据修订`。
- **常见误判**：把"指标显著"当成"构念成立"；忽略差异误分类的方向性后果；忽略指标被激励反向重塑（Goodhart 效应：考核什么就改变什么）。

**14. 选择偏差与幸存者偏差 selection / survivorship bias**
- **定义**：进入样本的机制与结果相关，样本不代表目标总体；幸存者偏差是其特例——只观测到存活、成功、被收录、被发表的个体。
- **如何识别**：样本来自"现存名单/成功案例/已上市/已发表/仍在营业"；排除标准明显与结局相关；效应估计对"是否纳入某类样本"敏感；历史研究只看到留下来的文献或档案。
- **必须追问**：个体是怎么进入样本的（入组、存续、发表、收录的条件是什么），这个条件与结局相关吗？被排除的是谁、有多少、后来怎样（失访、退市、未发表、删档）？目标总体到底是谁，结论能外推给谁？补上缺失者后效应方向会变吗？
- **检索线索**：`selection bias` `survivorship bias` `attrition` `publication bias` `left truncation` `immortal time bias` `file drawer`。
- **常见误判**：把现存成功者当总体（基金业绩、企业战略、历史文献）；只查"发表偏倚"这个词而不查未发表结果；忽略 immortal time bias（把用药后的存活时间算进用药组）。

**15. 相变 / 临界点 regime shift**
- **定义**：参数越过临界值时系统整体切换到另一状态，主导因素、反馈强度、甚至系数符号都变；不是同一关系的连续外推。
- **如何识别**：同一系统不同时期/地区出现两套规律（系数符号都变）；突变前后的波动性、恢复速度、自相关显著不同（早期预警信号）；历史序列上是跳变而非平滑趋势。
- **必须追问**：这套规律是在哪个 regime 下估的，外推边界在哪（边界通常就是临界点）？做过结构突变检验吗（Chow、Bai-Perron、Markov switching），还是默认参数稳定？跨过临界点后**哪些关系失效**（不是变强变弱，而是换规则）？有无滞后性（越过后回不去，hysteresis）？
- **检索线索**：`regime shift` `structural break` `tipping point` `phase transition` `early warning signal` `hysteresis` `Markov switching` `critical slowing down`。
- **常见误判**：把线性趋势外推到临界点之后；把突变后的新状态当"异常"，继续套旧模型；把临界前的波动增大当噪声。

## 二、复杂度分级 L1–L4

**定级是动作，不是标签**：定错的代价是用 L1 的自信写 L4 的结论。按下列判据逐级勾选，命中即取**最高**级。

**L1 单链 single chain**
- **判据**：一个主因→一个主果；时序清楚；无明显分层差异；最好有干预或准实验证据。
- **必须做**：机制链每一步各自有证据（不是整链只靠一条综述）；时序成立；至少一次反例检索。
- **结论强度上限**：可写"已确认（限定在…范围内）"。仍须过 #13 代理与 #14 选择的检查。

**L2 多因素并列 parallel factors**
- **判据**：多个因素共同影响结果，**且分层/交互检验已完成、未发现反号**。未做检验者不得定 L2——按 L3 处理并记 gap，否则等于把"没查"读成"没有"。
- **必须做**：9 轴清单过一遍，确认因素集不明显缺失；各自估主效应；查因素间相关（共线/混杂 #1）；看合计是否解释了主要变异。
- **结论强度上限**：可写"因素清单 + 各自方向与量级"；禁止写"某单一因素决定"。缺轴未查的进 gaps。

**L3 多因素 + 交互 + 异质 interacting & heterogeneous**
- **判据**：出现任一条——分层后效应反号或幅度差异大（#3）；两因素联合效应非可加（#4）；存在阈值/非线性（#8）；机制在不同案例里不同（#12）。
- **必须做**：分层/交互检验并报告每层估计；标明亚组是预设还是事后；解释异质性来源；必要时按层分结论而不是给平均值。
- **结论强度上限**：只能条件化——"对 X 层成立、对 Y 层不成立/反向"；给平均值的同时必须给出各层。

**L4 动态系统 feedback + lag + regime**
- **判据**：出现任一条——反馈回路（#9，因果图存在**双向边**）；同一变量对有两个方向的时间证据；时滞/累积暴露（#10）；路径依赖锁定（#11）；regime shift（#15）。
- **必须做**：画出因果图，标出回路与时滞；写明识别策略（IV/DiD/RDD/自然实验/模拟）及其依赖的假设；做**情景分析**（多情景 + 参数敏感性 + 阈值附近单独看）；**声明模型局限的三个最小字段：外推边界 / 被省略的回路 / 参数敏感性区间及其取值来源**。
- **结论强度上限**：只能写"条件性 + 情景 + 不确定性"；禁止单点预测，禁止"必然/一定"。

**四条硬规则**
1. **不可降级**：任一 L4 症状出现，不得用 L1–L3 的证据强度写结论——有反馈就不许说"X 导致 Y"，只能写"在给定情景下 X 与 Y 同向变动"。
2. **存疑取高**：判不准时按更高一级处理，并在报告里写"分级依据不足"。
3. **定级留痕**：报告须写明 complexity_level、命中的模式编号、因预算未查的轴。三项缺一项，定级不可复核。
4. **档位 ≠ 完成度**：档位由**问题结构**决定（有没有交互/反馈），完成度由**预算**决定。预算不足时不降档，而是把未做的检查标 `unchecked` 写进覆盖度声明——降档会让"没查"悄悄变成"不需要查"。另注：因素**数量**与档位正交，因素多但全线性仍是 L2，因素少但有强反馈是 L4。

## 三、因素完备性自检（9 轴）

**用法**：建问题树时过一遍，每轴至少产出一个候选因素，或明确写"不适用（附理由）"。空着不算过。

| 轴 | 该问什么 | 最容易漏什么 |
|---|---|---|
| 时间 | 观测窗口多长？因果间隔多久？结论只在这个时期成立吗（政策/技术/周期阶段）？ | 短窗口推长期；时滞与累积暴露（#10）；把结构性突变前后的数据混算（#15） |
| 空间层级 | 观测单位与推断单位是否同层？空间/网络边界怎么划？有无溢出 spillover？ | 生态谬误（#7）；处理组外溢污染对照组；边界被事后调整以迎合结论 |
| 主体 | 谁决策、谁受影响、谁没进样本？主体间激励与能力差异多大？ | 把机构/群体当同质；漏掉"未发声"的主体（#14）；只访谈可接触到的人 |
| 物质资源 | 实物/资金/能量约束是什么？替代品与供给弹性多大？ | 假设资源无限、成本不变；忽略约束下的挤出效应与零和竞争 |
| 规则制度 | 正式规则（法律/标准/合约）与非正式规范各是什么？谁执行、违规成本多少？ | 只查条文不查执行强度；忽略制度与结果互相塑造（#9） |
| 信息认知 | 各方掌握什么信息、如何传递、谁在解读？有无认知偏差与叙事？ | 假设完全信息与理性主体；忽略指标改变行为（Goodhart，#13） |
| 技术工具 | 关键技术的能力边界、成本曲线、替代节奏？采用门槛在哪？ | 把当前技术参数当外生常数；忽略网络效应与锁定（#11） |
| 环境冲击 | 外生冲击（疫情/灾害/战争/能源/政策突变）是否与主要变量同期？ | 把冲击造成的共同变化当因果（#1）；只用平稳期数据估长期关系 |
| 反馈动态 | 有回路吗？有阈值吗？系统当前在均衡还是过渡中？ | 默认单向因果（#9）；研究期没走完一个反馈周期就下结论 |

**收尾检查**：九轴里凡标"不适用"的必须有理由；凡标"未查"的必须进报告 gaps，并写明它对结论的威胁方向（高估 / 低估 / 方向不明）。
